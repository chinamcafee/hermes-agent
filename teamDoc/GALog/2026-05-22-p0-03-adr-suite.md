## 决策摘要

1. Casdoor 负责身份认证和生命周期，Team Cloud 负责产品实体映射。
2. SpiceDB 负责最终资源授权，所有危险和跨资源操作 fail closed。
3. PostgreSQL `memory_items` 是 canonical memory，pgvector 是默认派生索引。
4. MinIO 承载对象和备份，但所有对象必须有 PostgreSQL manifest 和审计。
5. Hermes runtime 通过 TeamContext、MemoryProvider 和 plugin hook 扩展，不承载最终企业权限边界。
